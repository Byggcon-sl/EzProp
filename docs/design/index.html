EzProp – tre designretninger

Skisser for å velge retning, ikke ferdig design. Hver retning viser dashbord, oppdragets hovedside, Konstruksjoner på PC og befaring på iPad (liggende og stående). Alle skjermer viser samme fiktive eksempel: Fjellveien 12, Bodø – Våtrom › Bad › «Vanntett sjikt, membran og sluk».

Anbefaling: A som grunnmur, med det beste fra B og C

  • Alle skjermer: A sitt rolige designspråk, så EzProp og Optiplan ser ut som én løsning.
  • PC på kontoret: tettheten fra B – oppdragskø med lagrede filtre, kontrollpanel for mangler før levering, «/» for fraser, hurtigtaster for TG og hendelseslogg som viser utløste handlinger. Gjerne som valg i innstillingene.
  • iPad på befaring: A sin ett-punkt-visning, med talltastatur og tegning av hvordan man måler fra C, store Ja/Nei-knapper nederst, og B sin «Hele rommet»-liste for erfarne takstmenn. Mørk visning som valg for loft og kjeller.
  • Skriving på PC: C sitt panel «Slik blir det i rapporten» ved siden av punktet.

Du bestemmer: hvilken retning som er grunnmur, om B sin tetthet er standard eller et valg på PC, og om mørk visning skal med i første versjon. Grenseverdiene i skissene (fall, terskel) er bare eksempler og må fastsettes av fagansvarlig.

Designprinsipper (fra researchen)

  • Arbeidskø før statistikk: dashbordet viser det som venter på deg.
  • Oppdragets status er ryggraden, med neste steg alltid synlig.
  • Én hovedhandling per skjerm.
  • Systemet foreslår, takstmannen bestemmer – TG-forslag med begrunnelse og kilde.
  • Tall i stedet for ja/nei for målinger.
  • iPad: trykkflater minst 44 pt, helst 56–72 for hovedknapper; ingen nedtrekksmenyer i befaringen.
  • Hovedknappene fast nederst i tommelsonen; kamera alltid ett trykk unna.
  • Rolig, alltid synlig status for nett og lagring.
  • Høy kontrast for sollys og mørke rom; TG alltid med tekst, aldri bare farge.
  • Samme data, to visninger: PC med tre kolonner, iPad med ett punkt om gangen.
  • Kontroll før levering underveis, ikke først til slutt.
