Skriftene i Byggcon-profilen, lagt i prosjektet slik at appen og byggingen virker uten internett.

- Inter (Regular 400, Medium 500, SemiBold 600, Bold 700): brødtekst og knapper. Lisens: SIL OFL 1.1, se `OFL-Inter.txt`.
- Schibsted Grotesk (Medium 500, SemiBold 600, Bold 700): overskrifter. Lisens: SIL OFL 1.1, se `OFL-SchibstedGrotesk.txt`.

Filene er de samme som i `docs/design/byggcon-profil/fonts/`.
